背景与接入示例

在「播放器设置 → 画布背景」指定用封面还是 PV，以及如何铺满或平铺整个预览框。

查看调用示例 
const view = mountPadview(stage);
await view.ready;
view.load(JSON.parse(chartJson), { chartJson });
view.setTime(2.5, { seek: true });
view.cover = coverInput;
view.video = videoInput;
view.configure({patch: {
  'params.canvas_background.source': 'cover',
  'params.canvas_background.layout': 'tile',
}});

宿主提供谱面秒数。有音乐时，本例使用音乐元素的 currentTime 减去谱面 audio_offset；没有音乐时，使用浏览器时钟。查看示例 Simai。
